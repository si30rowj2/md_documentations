# 機能仕様

## 機能一覧

| 機能ID | 機能名 | 概要 |
|--------|--------|------|
| F-001 | ログイン | 利用者認証を行う |
| F-002 | 在庫照会 | SKU・ロケーション単位で在庫を検索する |
| F-003 | 入庫登録 | 入庫実績を登録し在庫数を加算する |
| F-004 | 出庫登録 | 出庫実績を登録し在庫数を減算する |

## ログイン機能 (F-001)

### 画面仕様

ユーザ ID とパスワードを入力し認証する。5 回連続で失敗した場合、アカウントを 30 分間ロックする。

### 処理フロー

1. 入力値のバリデーション(ID: 半角英数 8 桁、パスワード: 12 文字以上)
2. パスワードハッシュ(bcrypt)の照合
3. セッショントークンの発行(有効期限 8 時間)

### エラー仕様

| コード | メッセージ | 条件 |
|--------|-----------|------|
| E-0101 | IDまたはパスワードが不正です | 認証失敗 |
| E-0102 | アカウントがロックされています | ロック中 |

## 在庫照会機能 (F-002)

### 検索条件

SKU コード(前方一致)、ロケーション(完全一致)、在庫区分(良品/不良品)を指定できる。

### API 仕様

```http
GET /api/v1/stocks?sku=A100&location=B-01-02
Authorization: Bearer {token}
```

レスポンス例:

```json
{
  "items": [
    { "sku": "A1001234", "location": "B-01-02", "qty": 120, "status": "good" }
  ],
  "total": 1
}
```
