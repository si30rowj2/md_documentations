# 在庫管理システム ソフトウェア仕様書

Version 1.0 / 株式会社サンプル 開発部

本サイトは在庫管理システムのソフトウェア仕様書です。左のナビゲーションから各章へ移動してください。

!!! note "章番号について"
    章の並び順と章番号は、リポジトリ直下の `docs.yml` 1 ファイルだけで決まります。
    ファイル名・フォルダ名・見出しには番号を書きません。番号は出力時に自動採番され、
    ページ本文だけでなくナビゲーションやページ内目次にも反映されます
    (例: 画面ページの H1 = `3-1.`、H2 = `3-1-1.`、H3 = `3-1-1-1.`)。

    章を途中に挿入するときも `docs.yml` に 1 行足すだけで、ファイルのリネームは不要です。
    そのため既存ページの URL も変わりません。このトップページは採番の対象外です。
