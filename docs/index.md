# 在庫管理システム ソフトウェア仕様書

Version 1.0 / 株式会社サンプル 開発部

本サイトは在庫管理システムのソフトウェア仕様書です。左のナビゲーションから各章へ移動してください。
ナビは大分類フォルダ・画面ファイルの数字プレフィックス順で自動生成されます。

!!! note "見出し番号について"
    見出し番号は「大分類-小分類」を起点に自動採番されます。大分類(画面仕様・API仕様 等)は
    フォルダ、小分類(各画面)はファイルで表し、番号はパスの数字プレフィックスから注入されます
    (例: 画面ページの H1 = `3-1.`、H2 = `3-1-1.`、H3 = `3-1-2.`)。
    このトップページは数字プレフィックスを持たないため採番対象外です。
