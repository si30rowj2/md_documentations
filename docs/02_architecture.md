# システム構成

## 全体構成

本システムは Web アプリケーションとして構築し、クライアント・API サーバ・データベースの 3 層構成とする。

```
[ブラウザ] --HTTPS--> [APIサーバ (Node.js)] ---> [PostgreSQL]
                              |
                              +--> [Redis (セッション/キャッシュ)]
```

## 技術スタック

| 層 | 技術 | バージョン |
|----|------|-----------|
| フロントエンド | Vue.js | 3.x |
| バックエンド | Node.js / Express | 20.x / 4.x |
| データベース | PostgreSQL | 16.x |
| キャッシュ | Redis | 7.x |

## コンポーネント構成

### API サーバ

REST API を提供する。認証・在庫・入出庫・マスタ管理の 4 モジュールで構成する。

### バッチ処理

夜間バッチとして以下を実行する。

1. 在庫スナップショットの作成(毎日 2:00)
2. 操作ログのアーカイブ(毎週日曜 3:00)

### 外部連携

基幹システムとは CSV ファイルの SFTP 連携とする。連携仕様は外部インタフェース仕様の章を参照。
