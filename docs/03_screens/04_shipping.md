# 出庫登録画面 (F-004)

出庫実績を登録し、対象 SKU・ロケーションの在庫数を減算する。

## 画面仕様

| 項目 | 型 | 必須 | 説明 |
|------|----|------|------|
| SKUコード | テキスト | ○ | 出庫対象の SKU |
| ロケーション | テキスト | ○ | 出庫元の棚位置 |
| 出庫数量 | 数値 | ○ | 1 以上の整数 |
| 登録ボタン | ボタン | - | 出庫実績を確定する |

## 処理フロー

1. 入力値のバリデーション(数量は 1 以上の整数)
2. 引当済み在庫数の確認(出庫可能数を超えないこと)
3. 対象 SKU・ロケーションの在庫数から出庫数量を減算
4. 出庫履歴の記録(登録者・登録日時)

## エラー仕様

| コード | メッセージ | 条件 |
|--------|-----------|------|
| E-0401 | 出庫数量が在庫数を超えています | 在庫不足 |
| E-0402 | 出庫数量は 1 以上で入力してください | 数量が 0 以下 |
