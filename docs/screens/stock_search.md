# 在庫照会画面 (F-002)

SKU・ロケーション単位で在庫を検索し、一覧表示する。検索結果は在庫照会 API を通じて取得する。

## 検索条件

SKU コード(前方一致)、ロケーション(完全一致)、在庫区分(良品/不良品)を指定できる。

| 項目 | 型 | 必須 | 説明 |
|------|----|------|------|
| SKUコード | テキスト | - | 前方一致で検索 |
| ロケーション | テキスト | - | 完全一致で検索 |
| 在庫区分 | プルダウン | - | 良品 / 不良品 |

## 検索結果一覧

| 列 | 説明 |
|----|------|
| SKU | 在庫の最小識別単位 |
| ロケーション | 棚位置コード |
| 数量 | 現在在庫数 |
| 在庫区分 | 良品 / 不良品 |

検索結果が 0 件の場合は「該当する在庫がありません」を表示する。
