# 概要

本書は在庫管理システム(以下、本システム)のソフトウェア仕様を定めるものである。

> **注**: 見出しに章番号は記載しない。番号は wiki.js / MkDocs 上では CSS カウンタ、PDF では Pandoc の `--number-sections` により自動採番される。

## 目的

本システムは、倉庫内の在庫情報をリアルタイムに管理し、入出庫作業の効率化と棚卸工数の削減を目的とする。

## 対象読者

本書は以下の読者を対象とする。

- 開発担当者(実装・テストの根拠として参照)
- 保守担当者(改修時の影響範囲調査に使用)
- 顧客側システム担当者(受入検収の基準として参照)

## 用語定義

| 用語 | 説明 |
|------|------|
| SKU | Stock Keeping Unit。在庫管理上の最小識別単位 |
| ロケーション | 倉庫内の棚位置を示すコード |
| 引当 | 出荷指示に対して在庫を確保する処理 |

## 機能一覧

本システムが提供する機能の一覧を示す。画面仕様・API仕様の各章は本一覧の機能IDに対応する。

| 機能ID | 機能名 | 概要 |
|--------|--------|------|
| F-001 | ログイン | 利用者認証を行う |
| F-002 | 在庫照会 | SKU・ロケーション単位で在庫を検索する |
| F-003 | 入庫登録 | 入庫実績を登録し在庫数を加算する |
| F-004 | 出庫登録 | 出庫実績を登録し在庫数を減算する |
